Objective

The goal of this project is to use WebVR (A-Frame) to construct a basic scene to learn common concepts in building 3D worlds. (Such concepts are also used in more advanced software like game engines, 3D modeling, etc.)

This is a team project. Please work with your team to brainstorm, design, implement, and report your scene.



About WebVR

We are using A-Frame to implement WebVR. Please see the attached files for the tutorial I wrote. Also, please refer to A-Frame's official website for more tutorials and examples.

Note: A-Frame is based on HTML and JavaScript, with which you can do programming. But essentially A-Frame can work like HTML, which is a "markup language". This means if you are concerned about programming, you don't need to treat it like a programming language, and can still complete this project. 🙂



Theme

Please brainstorm and create your A-Frame scene with this theme:  "Poem: Imagined, Interpreted, and Interactive".

Poems are written with words and phonetic structure (e.g., rhyming), yet their imagery and emotion invite re-interpretation beyond text. In this project, you and your team are to re-imagine (part of) a poem as an interactive WebVR scene using A-Frame, transforming the poem's description, emotion, and atmosphere into an interactive virtual world that reflects your team's own interpretation.

What can, and cannot, be chosen as the poem

The chosen poem must be originally written in either Chinese or English. It should have been publicly released for at least 50 years, and must be authored by a human poet.

These poems cannot be used for the project:

"江雪", 柳宗元
"早發白帝城 （下江陵）", 李白
"秋夕", 杜牧
"靜夜思", 李白
"春夜喜雨", 杜甫
"尋隱者不遇", 賈島
"春望", 杜甫
"楓橋夜泊", 張繼
"月下獨酌", 李白
"The Raven", Edgar Allan Poe
"A Room with a View", David Wagoner



Deliverables (Only one student in your team submits on behalf of the whole team.)

The scene file(s): the HTML file, and other asset files if used. Please make sure they can be read/loaded not just on your computer.

Please submit a zip file that has all the subfolders and files needed to run your A-Frame scene.

Note: If your work runs on an online platform (like GitHub), you can include the link in the report, but you also have to submit your codes in a zip file on Moodle as a double-check mechanism. This is for preventing the possible controversy that someone may keep modifying the online version after their Moodle submission. If for some reasons, your work runs on GitHub but not from the submitted codes, that's okay, as long as the codes on the two versions are the same.

A short report: No more than 2 pages, in PDF. It should include: (1) your team members' names (if there is a team member with zero contribution, please don't include his/her name); (2) using text and screenshot images to describe what your scene is about, and what/where to see items in your scene. Please include hyperlink to show the origin of the poem (for example, the poem's Wikipedia page).

If there are certain steps needed to run the A-Frame scene, please also provide such information in the report.

A “walk-through” screen capture video (no more than 90 seconds) to showcase your scene. You can use Windows' Game Bar (Windows key + G), or Mac's QuickTime.


Grading

Submission missing any of the items in Deliverables won't be graded.
A project based on the "cannot-be-used poem" won't be graded.

Each member in the same team will get the same grade for this project. Please work among yourselves to achieve good and balanced teamwork. Again, if there is a team member with zero contribution, please don't include his/her name in the report.

(If there is an extreme situation of contribution imbalance in your team, you can request to trigger a team peer assessment.)

Total: 30 pts
18 pts: Level of clarity from all the submitted files
12 pts: Level of shown efforts in interpreting the poem, and designing and implementing the scene

Violation of academic integrity will result in 0 point.

Late submission will not be graded unless proof of extreme circumstance (per University standard) is provided.

Please make sure your submitted files do not contain inappropriate or offensive content.
